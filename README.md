# Coursera Python Flask AI

This repository contains my Coursera project for developing a simple
AI-enabled web application using Python and Flask.

## Project Description

The goal of this project is to build a small web application using Flask
and integrate AI functionality through Python.

The project is used as part of a Coursera course and demonstrates basic
concepts such as:

- Python programming
- Flask web development
- REST APIs
- HTML templates
- AI integration
- Git and GitHub

## Technologies

- Python 3
- Flask
- HTML / CSS
- REST APIs
- Git
- GitHub
